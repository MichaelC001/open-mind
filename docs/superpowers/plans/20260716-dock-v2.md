# Dock v2 (Shortcut Rebinding + Quick-Tag) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebind the dock's global shortcuts from Settings, and tag a Quick Save from a panel confirm strip without opening the web app.

**Architecture:** Pure TS modules (accelerator normalisation, confirm-strip reducer) carry the logic and the tests; Rust persists shortcuts in a `shortcuts.json` under the app config dir (NOT the keychain — not secrets, and Rust needs them at startup) and gains a `rebind_shortcuts` command plus a `save-confirmed` event after Quick Save; SettingsView and Panel wire the UI.

**Tech Stack:** Tauri v2 (`tauri-plugin-global-shortcut` — `Shortcut` parses from string via `TryFrom<&str>`/`FromStr`, verify in the vendored crate), Vite/React/TS, vitest, existing keyring-based settings untouched.

**Spec:** `docs/superpowers/specs/20260716-dock-v2-design.md`

## Global Constraints

- Defaults unchanged: Quick Save `CmdOrCtrl+Shift+S`, Quick Find `CmdOrCtrl+Shift+O`; stored accelerators that fail to parse at startup → fall back to defaults (log, don't crash).
- Accelerator validity: ≥1 modifier (Cmd/Ctrl/Alt/Shift) + exactly one non-modifier key.
- Registration failure (combo taken) must degrade like startup does today (notify, tray works) and surface inline in Settings ("that combination is taken"), reverting the field.
- Quick-tag never blocks or fails the save (capture is sacred): the save completes first; tagging is a follow-up PATCH. Esc or 5 s idle dismisses without tagging.
- Token never logged; no new secrets surfaces. No banner comments. UK English copy.
- Dock commands: `pnpm --filter dock test` (vitest), `pnpm --filter dock build` (tsc+vite), `cargo build`/`cargo test` from `apps/dock/src-tauri`. npx is shimmed — use pnpm/./node_modules/.bin.

```ts
// accelerator.ts
export type CapturedKey = { key: string; code: string; metaKey: boolean; ctrlKey: boolean; altKey: boolean; shiftKey: boolean };
export function captureToAccelerator(e: CapturedKey): string | null; // null = invalid (modifier-only / bare key)
export const DEFAULT_QUICK_SAVE = "CmdOrCtrl+Shift+S";
export const DEFAULT_QUICK_FIND = "CmdOrCtrl+Shift+O";

// save-confirm.ts — pure reducer for the confirm strip
export type ConfirmState =
  | { kind: "hidden" }
  | { kind: "confirming"; itemId: string; title: string; tags: string }
  | { kind: "saving-tags"; itemId: string; title: string; tags: string }
  | { kind: "done" };
export type ConfirmEvent =
  | { type: "saved"; itemId: string; title: string }
  | { type: "type-tags"; tags: string }
  | { type: "submit" } | { type: "submit-ok" } | { type: "submit-failed" }
  | { type: "dismiss" } | { type: "idle-timeout" };
export function confirmReduce(s: ConfirmState, e: ConfirmEvent): ConfirmState;
export function parseTags(raw: string): string[]; // split on comma, trim, drop empties (server canonicalises further)
```
